# 原始資料放這裡

這個資料夾的內容**不納入版本控制**（見 `.gitignore`）：
管線 shapefile 的 `.dbf` 通常超過 GitHub 單檔 100 MB 的硬限制，
且原始圖資的開放範圍需另行確認。

網站本身不需要這些檔案 —— `data/` 底下已是建置好的成果。
只有要**重新建置**（新增月份、年度或更新圖資）時才需要把檔案放回來。

## 需要的檔案

```
source/
├── 管線人孔圖資/
│   ├── 管線0915.shp / .shx / .dbf / .prj / .cpg
│   └── 人孔0915.shp / .shx / .dbf / .prj / .cpg
└── 115年度列管人孔開孔狀態統計_20260915.xlsx
```

檔名與路徑由 `tools/config.json` 指定，可自行調整。

## 各檔案用到的欄位

| 圖層 | 必要欄位 |
|---|---|
| 管線 | `行政區`、`US_MH`、`DS_MH`、`US_MH_X/Y`、`DS_MH_X/Y`、`PI_NUM` |
| 人孔 | `行政區`、`NUM`、`Type`（正常／覆蓋／虛人）、`ROAD_NAME` |
| Excel 工作表 1 | 行政區、人孔編號（列管清單） |
| Excel 工作表 2 | 行政區、人孔編號、檢查日期（開孔紀錄） |

座標系統預設 TWD97 二度分帶（EPSG:3826），可在 `config.json` 的 `source_crs` 調整。
